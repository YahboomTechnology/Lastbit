# Last:bit Tracked Robot Car for BBC micro:bit, Voice Interaction, MakeCode/MicroPython Programming, STEM Education
![](https://github.com/YahboomTechnology/Lastbit/blob/main/Lastbit.jpg)
# Introduction
The Last:bit robot is a tracked robot car developed based on the BBC micro:bit, specifically designed for programming learning and STEM education. Equipped with a 3DOF robotic arm, it can simulate industrial robots to perform object grasping and transportation. Integrated voice interaction module, the robot can "listen" and "speak." Combined with a wealth of hardware such as ultrasonic sensors, infrared line tracking sensors, sound and temperature sensors, and RGB LED lights, it possesses comprehensive environmental perception capabilities and stunning visual effects. It supports infrared remote control and mobile APP control. Yahboom provide two programming courses: Makecode graphical programming and MicroPython, along with 100+ tutorials. Whether children are beginners or have some programming experience, they can systematically learn and master programming knowledge and logical thinking through hands-on practice and fun activities.
# Features
* 3-DOF Robotic Arm: Let Your Robot Get Hands-On

The standard configuration includes a 3-DOF robotic arm equipped with three 9G metal digital servos, supporting flexible movement in multiple angles, including up/down and left/right. It comes with five EVA cubes, allowing for direct simulation of object grasping, carrying, and placement.

* Intelligent Voice Interaction: Enabling Robots to "Understand Commands"

The superior comes with an integrated AI voice interaction module. Through preset voice phrases, it enables voice wake-up, command recognition, and voice broadcasting, providing Last:bit with more engaging human-robot interaction experience.
Note: The voice module uses a fixed command recognition method, rather than a large language model for free dialogue.

* MakeCode Graphical + MicroPython Programming: From Beginner to Advanced Coding 

Last:bit offers two programming learning materials: MakeCode graphical and MicroPython, catering to different learning stages. 100+ courses and project examples cover the learning process from basic control to comprehensive robot applications.

* 1:90 High Reduction Ratio TT Motor + All-Aluminum Alloy Body: Performance Meets Premium Design

The all-aluminum alloy body and high-quality tracks, coupled with a 1:90 high reduction ratio TT motor, provide the robot with ample driving force, giving the robot more power reserves when carrying a robotic arm and performing tasks such as grasping and carrying.

* Multi-functional Expansion Board: Unlock Multiple Robot Car Projects

Yahboom designed a multi-functional expansion board for Last:bit, integrating various commonly used sensors and execution modules. Through different sensor and program combinations, it can realize many robot tasks such as line tracking, obstacle avoidance, light-seeking, temperature detection, and sound monitoring, lighting effects, etc. exploring more interesting interactive projects.

* Multiple control methods + Building block expansion: More Possibilities. More Creativity

Last:bit supports three control methods: infrared remote control, mobile APP, and micro:bit handle (sold separately). This allows for quick experience of robot movement or more flexible wireless control. It also supports block structure expansion, allowing users to freely create robots with different shapes.
